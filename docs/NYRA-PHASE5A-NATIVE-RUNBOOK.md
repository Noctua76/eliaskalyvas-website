```sql
SELECT n.nspname,p.proname,p.prosecdef,p.proconfig,
 has_function_privilege('anon',p.oid,'EXECUTE') AS anon_exec,
 has_function_privilege('authenticated',p.oid,'EXECUTE') AS authenticated_exec,
 has_function_privilege('service_role',p.oid,'EXECUTE') AS service_exec
FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
WHERE n.nspname='public' AND
 (p.proname LIKE 'nyra_publication_%' OR p.proname LIKE 'nyra_delivery_%')
ORDER BY 1,2;
SELECT n.nspname,c.relname,c.relrowsecurity,c.relacl
FROM pg_class c JOIN pg_namespace n ON n.oid=c.relnamespace
WHERE c.relkind='r' AND (n.nspname='nyra_delivery' OR
 (n.nspname='public' AND c.relname LIKE 'nyra_publication_%')) ORDER BY 1,2;
SELECT column_name,privilege_type FROM information_schema.column_privileges
WHERE table_schema='auth' AND table_name='sessions' AND grantee='service_role'
ORDER BY 1,2;
SELECT a.attname,has_column_privilege('service_role',a.attrelid,a.attnum,'SELECT')
FROM pg_attribute a WHERE a.attrelid='auth.sessions'::regclass
AND a.attnum>0 AND NOT a.attisdropped ORDER BY a.attnum;
```

## Independent native connection matrix — required test implementation

Each race needs two independent clients, different pg_backend_pid values, explicit transaction barriers, bounded statement/lock timeouts and a third monitoring connection inspecting pg_stat_activity/pg_locks. A short delay or two awaited calls alone is not concurrency proof. Capture locks and sanitized SQLSTATEs. No SQL role switch is evidence of real JWT/MFA.

| ID | Interleaving / required invariant |
| --- | --- |
| C01 | Two identical authorize requests: one immutable decision, exact idempotent retry; different payload/identity cannot reuse request ID |
| C02 | Two distinct approvals for same generation: serialize or reject stale loser; no lost update |
| C03 | Edit selected revision while authorization locks it: serialize or deny stale preview; hash binding remains exact |
| C04 | Two delivery_claim connections: second waits on actual control lock, then DELIVERY_LEASE_BUSY; no second lease |
| C05 | Expire/reacquire lease: fence increases; former holder cannot persist candidate/export/artifact/permit/receipt |
| C06 | New authorized generation after export/permit: stale start denied; unrelated authorized immutable releases retained |
| C07 | Same JTI/run tuple replay and wrong SHA/attempt: replay denied and tuple binding intact |
| C08 | Inject invalid digest after partial provenance work: transaction abort leaves no artifact/provenance rows; exact valid retry succeeds once |
| C09 | Disconnect before commit vs after commit/before response: rollback or exact idempotent durable result, no invented completion/automatic redispatch |
| C10 | Started/unknown dispatch: no lease stealing/unsafe retry; only authoritative never-deployed evidence permits safe recovery |
| C11 | Wrong/foreign candidate transition digest: receipt rejected; matching duplicate receipt idempotent |
| C12 | Valid local observation within 15/30 bounds: one receipt and exact verified baseline advancement; late/uncertain remains reconciliation/timing_exception |
| C13 | Publish then withdraw/replace before first live: private intents preserved, no fabricated public history/date; GR/EN independent |
| C14 | UPDATE/DELETE approved decisions/releases/candidates/receipts as service_role: denied/immutable, row digest unchanged |

C12 uses synthetic local observation facts and proves native transaction persistence only. It is **not** real GitHub/Pages provenance, a live production witness or independent verified-live acceptance. Repeat each race with reversed scheduling and both language variants. On failure stop and return exact code/RPC reference; do not modify migrations/production code.
